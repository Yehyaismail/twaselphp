# مشروع تواصل — نسخة PHP وMySQL

هذه نسخة PHP من مشروع التواصل المرفق، صُممت لتعمل على استضافات PHP/MySQL المجانية مع الحفاظ على التخطيط المرئي للنسخة الأصلية قدر الإمكان. تعتمد النسخة على **PHP 8+** و**MySQL 5.7+/8.0** وواجهة أمامية مبنية بـ HTML وTailwind CDN وJavaScript مباشر، لذلك لا تحتاج إلى بناء React أو Node.js على الاستضافة.

## بيانات الدخول الافتراضية

| النوع | القيمة |
|---|---|
| بريد المدير | `admin@example.com` |
| كلمة مرور المدير | `admin123` |
| ملف التركيب | `install.php` |

> **مهم جداً:** بعد أول دخول، غيّر كلمة مرور المدير واحذف ملف `install.php` من الخادم.

## بنية المشروع

| المسار | الغرض |
|---|---|
| `index.php` | صفحة الواجهة الرئيسية التي تعرض التطبيق. |
| `api/index.php` | راوتر API لجميع العمليات: الدخول، المستخدمون، الرسائل، الرفع، الإدارة. |
| `config/config.php` | إعدادات قاعدة البيانات والرفع وحساب المدير الافتراضي. |
| `config/bootstrap.php` | اتصال PDO ودوال الجلسات والاستجابة والأمان. |
| `database/schema.sql` | سكربت قاعدة MySQL جاهز للاستيراد. |
| `assets/js/app.js` | الواجهة التفاعلية للدردشة ولوحة الإدارة. |
| `assets/css/styles.css` | تخصيصات CSS المطابقة للتصميم الأصلي. |
| `.htaccess` | توجيه Apache وحماية المجلدات الحساسة. |
| `router.php` | راوتر للتجربة المحلية فقط مع خادم PHP المدمج. |

## خطوات النشر على استضافة مجانية

1. ارفع محتويات مجلد المشروع إلى `public_html` أو المسار العام في الاستضافة.
2. أنشئ قاعدة بيانات MySQL من لوحة التحكم، ثم أنشئ مستخدماً واربطه بكامل صلاحيات القاعدة.
3. افتح الملف `config/config.php` وعدّل القيم التالية حسب بيانات الاستضافة:

```php
'host' => 'HOST_FROM_HOSTING',
'name' => 'DATABASE_NAME',
'user' => 'DATABASE_USER',
'pass' => 'DATABASE_PASSWORD',
```

4. افتح من المتصفح الرابط: `https://your-domain.example/install.php` ثم اضغط زر التركيب.
5. بعد نجاح التركيب، افتح الموقع وسجل الدخول بحساب المدير الافتراضي.
6. احذف `install.php` فوراً بعد الانتهاء، ثم غيّر كلمة المرور.

## طريقة التركيب اليدوي عبر phpMyAdmin

إذا كانت الاستضافة تمنع إنشاء قاعدة من PHP، افتح phpMyAdmin واختر قاعدة البيانات ثم استورد الملف `database/schema.sql`. بعد ذلك افتح `install.php` ليضيف حساب المدير أو أنشئ المدير يدوياً من لوحة قاعدة البيانات مع استخدام كلمة مرور مشفرة عبر `password_hash`.

## ملاحظات تطوير مستقبلية

استخدمت النسخة الحالية **Prepared Statements** في كل الاستعلامات الأساسية لمنع SQL Injection، كما أن الجلسات تستخدم Cookies بخاصية `HttpOnly` و`SameSite=Lax`. جداول الرسائل والملفات والتفاعلات والألقاب مفصولة لتسهيل إضافة ميزات مثل مجموعات المحادثة، تنبيهات الويب، البحث الكامل في الرسائل، أو أرشفة المحادثات.

| مجال التطوير | أين تبدأ؟ |
|---|---|
| إضافة مجموعات | أضف جداول `groups` و`group_members` ووسّع `messages` بدعم `group_id`. |
| تغيير تصميم الواجهة | عدّل `assets/css/styles.css` وكتل HTML في `assets/js/app.js`. |
| إضافة إشعارات فورية | يمكن استخدام WebSocket خارجي أو Long Polling من خلال API جديد. |
| رفع ملفات أكبر | عدّل `max_upload_size` في `config/config.php` وإعدادات PHP في الاستضافة. |

## اختبار محلي اختياري

```bash
export DB_HOST=127.0.0.1
export DB_NAME=tawasul_php
export DB_USER=tawasul
export DB_PASS=tawasul_pass_123
php -S 0.0.0.0:8000 router.php
```

ثم افتح `http://localhost:8000`.

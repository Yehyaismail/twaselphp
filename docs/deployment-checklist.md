# قائمة تحقق النشر

استخدم هذه القائمة قبل رفع مشروع تواصل PHP إلى الاستضافة العامة.

| البند | الحالة المطلوبة |
|---|---|
| نسخة PHP | PHP 8.0 أو أحدث مع امتداد `pdo_mysql`. |
| قاعدة البيانات | MySQL 5.7 أو MySQL 8.0 بترميز `utf8mb4_unicode_ci`. |
| صلاحيات مجلد `uploads` | قابلة للكتابة من PHP، عادة `755` أو `775` حسب الاستضافة. |
| ملف `.htaccess` | موجود ومسموح به في Apache. |
| ملف `install.php` | يحذف بعد نجاح التركيب. |
| كلمة مرور المدير | تغيّر فور أول دخول. |
| حجم الرفع | يطابق `upload_max_filesize` و`post_max_size` في إعدادات PHP. |

## أوامر فحص مفيدة على الخادم إن توفرت SSH

```bash
php -v
php -m | grep pdo_mysql
find . -name '*.php' -print0 | xargs -0 -n1 php -l
```

## ملاحظة الاستضافة المجانية

بعض الاستضافات المجانية تعطل دوال مثل `finfo` أو تمنع رفع ملفات كبيرة. إن حدث ذلك، خفّض حجم الملفات أو اطلب تفعيل امتداد `fileinfo` من لوحة الاستضافة.
